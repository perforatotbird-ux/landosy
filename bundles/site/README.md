# The Bundle Edit

Статический многостраничный лендинг-журнал для подборки `bundles/top25.txt`.

## Страницы

- `index.html` — главная витрина с hero, избранными наборами, категориями, журналом и CTA.
- `catalog.html` — все 25 товаров с поиском, фильтром и сортировкой.
- `products/*.html` — отдельная страница для каждого товара с полным описанием, форматами, сценарным отзывом, похожими товарами и партнёрским CTA.
- `blog.html` — журнал.
- `articles/*.html` — четыре статьи со ссылками на товары и другие статьи.
- `about.html` — информация о подборке, FAQ и раскрытие партнёрской ссылки.

## Запуск локально

Из этой папки можно запустить любой статический сервер:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

После запуска откройте `http://localhost:4173/`.

Сайт не требует сборщика или npm-зависимостей. Данные находятся в `assets/products.js`, логика — в `assets/app.js`, стили — в `styles.css`, а локальные изображения скопированы в `images/`.

> Все внешние CTA в интерфейсе используют реферальную ссылку `https://www.creativefabrica.com/bundles/ref/15072325/`. Отзывы на карточках помечены как редакционные сценарии, а не как независимые подтверждённые отзывы.
